# func_80020DD8 — MATCHED (83/83), round 6, runner charlie

Unit `src/code_a0bc.c`. A primitive handler (row 0, column 6 of the
handler table): for each of `n` flat unlit TMD triangles it transforms the
three vertices (`rtpt`), drops the triangle on any GTE flag in
0x7F85E000 or when `nclip` says it faces away, writes the screen XYs into
a POLY_F3, depth-cues the triangle's colour by IR0 (`dpcs`), links the
packet into the ordering table at `otz >> shift` and steps to the next
packet. Returns the next free packet.

```c
typedef struct {
    u32 hdr;
    CVECTOR rgb;
    u16 v0;
    u16 v1;
    u16 v2;
    u16 pad;
} TmdF3;

PACKET *func_80020DD8(TmdF3 *prim, SVECTOR *vtx, POLY_F3 *pkt, s32 n, s32 shift, GsOT *ot) {
    s32 v;
    s32 dp;
    s32 i;
    u32 *tag;

    for (i = 0; i < n; i++, prim++) {
        gte_ldv3(&vtx[prim->v0], &vtx[prim->v1], &vtx[prim->v2]);
        gte_rtpt();
        gte_stflg(&v);
        if (v & 0x7F85E000) {
            continue;
        }
        gte_nclip();
        gte_stopz(&v);
        if (v <= 0) {
            continue;
        }
        gte_stsxy3_f3(pkt);
        gte_avsz3();
        gte_stotz(&v);
        gte_stdp(&dp);
        gte_ldrgb(&prim->rgb);
        gte_lddp(dp);
        gte_dpcs();
        gte_strgb(&pkt->r0);
        tag = (u32 *)ot->org + (v >> shift);
        *(u32 *)pkt = (*tag & 0xFFFFFF) | 0x04000000;
        *tag = (u32)pkt & 0xFFFFFF;
        pkt++;
    }
    return (PACKET *)pkt;
}
```
