holds the target object's id (bits 0..11), a "packed rotation" flag (bit
15), and otherwise the key type (bits 16..19), its flags (20..23) and its
length in words (24..31). A packed key (bit 15 set, id not 1) is a type-1
rotation whose three 16-bit angles start in the header's upper half; bits
12..14 mark angles left out (zero), and its length is 1 word if any are
left out, else 2. `arg5 & 0x7F` filters keys: 1 skips objects 2..10, 2
skips objects 1 and 11..16.

one gets a scratch `GsDOBJ2`, matrix and `GsCOORD2PARAM` on the stack).

  12; for objects 2 and 10 with `arg5 & 0x80` the y rotation instead turns
  toward the camera target, clamped and eased into `D_80095740` (by 8,
  copied to `D_8009EF00`) or `D_80095744` (by 50). Flag 4 sets the scale

  `ScaleMatrix`, and with flag 8 the translation (words / 5) and

- Type 2: links the model `func_80019874(arg3, arg2, key)` to the object
  (`GsLinkObject4`).
- Type 3 (unless `arg4` is 2): parents the object to another slot's
  coordinate system (`super`), or to none for key 0 or 0xFFFF.
- Type 8: flag 0 allocates a slot for the id (`func_80019730`), flag 1
