# func_8002C20C — MATCHED 42/42 (round 6, alpha)

Unit `src/code_1a098.c`. Initialises a model object (`GsDOBJ2` followed by
its own `GsCOORDINATE2`, a rotation and a scale `SVECTOR`, new unit-local
view `Model70`): coordinate system under WORLD, maps the TMD at `tmd + 1`,
links object `n` of it, sets attribute 0x200, scale 1.0 and rotation 0,
and bumps the counter `D_8009588E`.

```c
void func_8002C20C(Model70 *m, unsigned long *tmd, u8 n) {
    GsInitCoordinate2(WORLD, &m->coord);
    m->obj.coord2 = &m->coord;
    tmd++;
    GsMapModelingData(tmd);
    tmd += 2;
    GsLinkObject4((unsigned long)tmd, &m->obj, n);
    m->obj.attribute = 0x200;
    m->scale.vx = 0x1000;
    m->scale.vy = 0x1000;
    m->scale.vz = 0x1000;
    m->rot.vx = 0;
    m->rot.vy = 0;
    m->rot.vz = 0;
    D_8009588E++;
}
```

Fourth build.

- Build 1, `GsMapModelingData(tmd + 1)` / `GsLinkObject4((u_long)(tmd +
  3), ...)`: 6/42 and a size change; retail keeps `tmd + 1` in `$s0` and
  passes `$s0 + 8`, so the parameter was advanced.
- Builds 2 and 3, `tmd++;` then `tmd + 2` (with the `coord2` store before
  or after `tmd++`): 25/42, `m` and `tmd` in swapped saved registers
  (`$s0`/`$s1`).
- Build 4, a second in-place step `tmd += 2;` before the link call: 42/42.

`D_8009588E` was a local extern in code_24748.c; it moved to
`include/common.h` (additive, `s16` as before) and the local copy was
deleted.

### Proposed learning

- A parameter advanced in steps (`p++; f(p); p += 2; g((u_long)p);`) can
  pair saved registers differently from one advance plus a constant offset
  (`p++; f(p); g(p + 2);`), even though the code is the same length.

The TMD parameter is `unsigned long *`, Sony's spelling: the project's
`u_long` is `u32` (`unsigned int`), and passing it drew an
incompatible-pointer warning for `GsMapModelingData`.
