## Reading the asm

- All six block moves are struct copies of one-member `u8 b[N]` structs:
  the rodata sources and the header destinations get a runtime alignment
  test with an `lwl`/`lwr` path; the stack side is known aligned.
- A 0x20-byte copy is unrolled; 0x80 and 0xC0 bytes loop 16 bytes a pass.

### Proposed learning

- **A block move whose destination base sits in its own register (`$t0`),
  batches of three words: the destination is an unknown-size array**,
  `*(T *)D = x;`. A member of a struct global at a fixed offset folds the
  offset into each store and copies four words a batch. A second copy whose
  address is that base plus a constant (`addiu a0, v0, 0x20`) is `D + 0x20`
  on the same array. (func_80037CF0)
