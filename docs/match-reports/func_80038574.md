Unit `src/code_27bc8.c`. Sums the halfword at 0x14 of the first `D_800959DC` 0x18-byte records of `D_800DF858` into an `s16`, and returns -1 if the sum is positive, 0 otherwise.

    s16 sum;
    s16 i;

    sum = 0;
    for (i = 0; i < D_800959DC; i++) {

Matched on the first build. `D_800DF858` is reached `lui`/`addiu` with the
record base in a register, so it is an array of a unit-local `Rec18`
(0x14 bytes unknown, `u16 unk14`, 2 bytes unknown). The `s16` counter and
sum give the `sll`/`sra` pairs; `if (sum > 0) return -1;` gives `bgtz` on
the shifted sum with -1 in its delay slot.

`Rec18` became the file name plus a `BlockCount` union in round 5 (see
`func_80037C2C.md`); the code above uses the new member names.
