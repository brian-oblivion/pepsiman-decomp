# func_80023194 — MATCHED 37/37 (round 3, delta)

Unit `src/code_13068.c`. Transforms a point by a coordinate system: gets
its local-screen and world-screen matrices (`GsGetLws`), makes the first
current, runs `RotTrans` on a copy of the `SVECTOR`, copies the three
results out, and restores the world matrix as the current one.

```c
/* MATCHING: the unused pair puts flag at sp+0x70 and the frame at 0x88. */
void func_80023194(GsCOORDINATE2 *coord, SVECTOR *pos, VECTOR *out) {
    MATRIX world;
    MATRIX local;
    SVECTOR v;
    VECTOR t;
    s32 unused[2];
    long flag;

    v.vx = pos->vx;
    v.vy = pos->vy;
    v.vz = pos->vz;
    GsGetLws(coord, &local, &world);
    GsSetLsMatrix(&local);
    RotTrans(&v, &t, &flag);
    out->vx = t.vx;
    out->vy = t.vy;
    out->vz = t.vz;
    GsSetLsMatrix(&world);
}
```

The unit now includes `libgpu.h` and `libgs.h` (after `libgte.h`) for
`GsCOORDINATE2`, `GsGetLws` and `GsSetLsMatrix`.

## Levers

- **Locals are laid out in declaration order** from sp+0x10: `world`
  (0x10), `local` (0x30), `v` (0x50), `t` (0x58). The `GsGetLws` arguments
  (`a1 = sp+0x30`, `a2 = sp+0x10`) fix which matrix is which.
- **An 8-byte hole between `t` (ends 0x68) and `flag` (0x70).** Without it
  the build was 28/37: same code, every frame offset 8 short (frame 0x80,
  `flag` at 0x68). An unused `s32 unused[2];` between them fills the hole.
  This is round 1's unused-local lever (func_80014CF0) on a non-leaf frame.
  It adds `-Wall`'s "unused variable `unused'", NEW for code_13068 in
  `tools/typeviews.py --warnings`; the head baselines it.

### Proposed learning

The unused-local lever also sizes a non-leaf frame: a hole between two
stack locals (every offset after it, the frame and the saved registers 8
short) is an unused local declared at that point in the list.
