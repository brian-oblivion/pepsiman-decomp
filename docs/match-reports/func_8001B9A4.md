# func_8001B9A4 — MATCHED (486/486), round 10, runner charlie

Unit `src/code_a0bc.c`. The quad twin of func_8001B4BC: the subdividing
handler for flat unlit quads (`TmdF4`, handler table row 4, column 7). Per
front-facing quad: depth from the screen Zs over 4, a depth-cued POLY_F4
one OT slot further in unless the transform overflowed, and under depth
250 a split into four quads at the four edge midpoints and the centre,
each drawn with the TMD colour copied as a word.

New: `gte_stsz4c(r1)` in `include/gte.h` (additive; Sony's name, SZ0-SZ3
at +0, +4, +8, +0xC from one base). The local prototype changed from
`PACKET *func_8001B9A4();` to the full one.

PACKET *func_8001B9A4(TmdF4 *prim, SVECTOR *vtx, POLY_F4 *pkt, s32 n, s32 shift, GsOT *ot) {
    SVECTOR m[5];
    s32 sz[4];
    s32 flg;
    s32 v;
    s32 dp;
    s32 i;
    s32 j;
    u32 *tag;

    for (i = 0; i < n; i++, prim++) {
        gte_ldv3(&vtx[prim->v0], &vtx[prim->v1], &vtx[prim->v2]);
        gte_rtpt();
        gte_stflg(&flg);
        gte_nclip();
        gte_stopz(&v);
        if (v <= 0) {
            continue;
        }
        gte_stsxy3_f4(pkt);
        gte_ldv0(&vtx[prim->v3]);
        gte_rtps();
        gte_stflg(&v);
        gte_stsxy2(&pkt->x3);
        gte_stsz4c(sz);
        if (sz[0] > sz[1]) {
            v = sz[0];
        } else {
            v = sz[1];
        }
        if (sz[2] > v) {
            v = sz[2];
        } else if (sz[3] > v) {
            v = sz[3];
        }
        v >>= 2;
        gte_stdp(&dp);
        if (flg >= 0) {
            gte_ldrgb(&prim->rgb);
            gte_lddp(dp);
            gte_dpcs();
            gte_strgb(&pkt->r0);
            tag = (u32 *)ot->org + (v >> shift) + 1;
            *(u32 *)pkt = (*tag & 0xFFFFFF) | 0x05000000;
            *tag = (u32)pkt & 0xFFFFFF;
            pkt++;
        }
        tag = (u32 *)ot->org + (v >> shift);
        if (v < 250) {
            m[0].vx = (vtx[prim->v0].vx + vtx[prim->v1].vx) >> 1;
            m[0].vy = (vtx[prim->v0].vy + vtx[prim->v1].vy) >> 1;
            m[0].vz = (vtx[prim->v0].vz + vtx[prim->v1].vz) >> 1;
            m[1].vx = (vtx[prim->v0].vx + vtx[prim->v2].vx) >> 1;
            m[1].vy = (vtx[prim->v0].vy + vtx[prim->v2].vy) >> 1;
            m[1].vz = (vtx[prim->v0].vz + vtx[prim->v2].vz) >> 1;
            m[2].vx = (vtx[prim->v1].vx + vtx[prim->v3].vx) >> 1;
            m[2].vy = (vtx[prim->v1].vy + vtx[prim->v3].vy) >> 1;
            m[2].vz = (vtx[prim->v1].vz + vtx[prim->v3].vz) >> 1;
            m[3].vx = (vtx[prim->v2].vx + vtx[prim->v3].vx) >> 1;
            m[3].vy = (vtx[prim->v2].vy + vtx[prim->v3].vy) >> 1;
            m[3].vz = (vtx[prim->v2].vz + vtx[prim->v3].vz) >> 1;
            m[4].vx = (vtx[prim->v0].vx + vtx[prim->v1].vx + vtx[prim->v2].vx + vtx[prim->v3].vx) >> 2;
            m[4].vy = (vtx[prim->v0].vy + vtx[prim->v1].vy + vtx[prim->v2].vy + vtx[prim->v3].vy) >> 2;
            m[4].vz = (vtx[prim->v0].vz + vtx[prim->v1].vz + vtx[prim->v2].vz + vtx[prim->v3].vz) >> 2;
            for (j = 0; j < 4; j++) {
                switch (j) {
                    case 0:
                        gte_ldv3(&vtx[prim->v0], &m[0], &m[1]);
                        break;
                    case 1:
                        gte_ldv3(&m[0], &vtx[prim->v1], &m[4]);
                        break;
                    case 2:
                        gte_ldv3(&m[1], &m[4], &vtx[prim->v2]);
                        break;
                    case 3:
                        gte_ldv3(&m[4], &m[2], &m[3]);
                        break;
                }
                gte_rtpt();
                gte_stflg(&v);
                if (v & 0x7F85E000) {
                    continue;
                }
                gte_stsxy3_f4(pkt);
                switch (j) {
                    case 0:
                        gte_ldv0(&m[4]);
                        break;
                    case 1:
                        gte_ldv0(&m[2]);
                        break;
                    case 2:
                        gte_ldv0(&m[3]);
                        break;
                    case 3:
                        gte_ldv0(&vtx[prim->v3]);
                        break;
                }
                gte_rtps();
                gte_stflg(&v);
                if (v & 0x7F85E000) {
                    continue;
                }
                gte_stsxy2(&pkt->x3);
                *(u32 *)&pkt->r0 = *(u32 *)&prim->rgb;
                *(u32 *)pkt = (*tag & 0xFFFFFF) | 0x05000000;
                *tag = (u32)pkt & 0xFFFFFF;
                pkt++;
            }
        }
    }
    return (PACKET *)pkt;
}

## How it went

1. func_8001B4BC's body transposed to quads after reading the asm for the
   differences: the second `rtps` for vertex 3 stores the flag into `v`
   with no test; `swc2 $16..$19` off one base (`gte_stsz4c`); five
   midpoints (`m[4]` the centre, `>> 2` of a four-term sum); a second
   `switch (j)` picks the fourth corner for `ldv0` before the sub-quad's
   own `rtps` and flag test.
2. The depth "max" in retail is not a max: after `sz[0]`/`sz[1]`, it is
   `if (sz[2] > v) v = sz[2]; else if (sz[3] > v) v = sz[3];` (the `bnez`
   to the shared store skips the `sz[3]` test). Written so: 486/486 on the
   first build.

### Proposed learning

- Four consecutive `swc2 $16..$19` at +0..+0xC from one register:
  `gte_stsz4c(arr)` (now in include/gte.h).
