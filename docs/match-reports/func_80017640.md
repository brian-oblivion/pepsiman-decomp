# func_80017640 — MATCHED (77/77), round 7, runner alpha

Unit `src/code_7d74.c`. Parses a TIM header into the TimInfo at
`D_800956D4`: checks the 0x10 id, unpacks the pixel mode and the CLUT
flag, records the CLUT's rect and data when present, then the image's
rect and pixels, and the width scaled by mode (x4 at 4 bpp, x2 at 8 bpp,
x1 otherwise) with that scale in `unk1E`. Returns -1 on a bad id, else 0.

```c
#define sTim ((TimInfo *)D_800956D4)

s8 func_80017640(u16 *tim) {
    u16 *p;
    u16 *start;
    s32 len;
    s32 c;

    p = tim;
    if (*p != 0x10) {
        return -1;
    }
    p += 2;
    sTim->mode = *p & 7;
    c = *p & 8;
    sTim->hasClut = c != 0;
    if (sTim->hasClut) {
        p += 2;
        start = p;
        len = *p;
        p += 2;
        sTim->clutRect.x = *p++;
        sTim->clutRect.y = *p++;
        sTim->clutRect.w = *p++;
        sTim->clutRect.h = *p++;
        sTim->clut = (u32 *)p;
        p = (u16 *)((u8 *)start + len);
    } else {
        p += 2;
    }
    p += 2;
    sTim->pixRect.x = *p++;
    sTim->pixRect.y = *p++;
    sTim->pixRect.w = *p++;
    sTim->pixRect.h = *p++;
    sTim->pixel = (u32 *)p;
    switch (sTim->mode) {
        case 0:
            sTim->unk1E = 4;
            sTim->unk1C = sTim->pixRect.w * 4;
            break;
        case 1:
            sTim->unk1E = 2;
            sTim->unk1C = sTim->pixRect.w * 2;
            break;
        default:
            sTim->unk1C = sTim->pixRect.w;
            break;
    }
    return 0;
}
```

## Attempts (about 12, each through the oracle)

1. The body above with `hasClut = (*p & 8) != 0`, `u16 len` and `w << 2`
   / `w << 1`: 72/77 (word count off by one from an `andi 0xFFFF` on
   `len`; `srl 3` + `andi 1` for the flag; `lhu` for the width in cases 0
   and 1).
2. `len` as `s32`: the `andi` goes. 73/77.
3. Flag spellings that all still gave `srl`/`andi 1`: `(u32)(x & 8) > 0`,
   `? 1 : 0`, `== 8`, `(s16)(x & 8) != 0`, `0 < (x & 8)`, `c = *p; (c & 8)
   != 0`. `(*(u32 *)p & 8) != 0` was worse (72).
4. `c = *p & 8; hasClut = c != 0;`: `andi 8` + `sltu`. 75/77.
5. `w * 4` and `w * 2` instead of shifts: `lh` like retail. 77/77.
   (`(s32)w << 2`, `(u16)w << 2`, `w + w + w + w` all stayed `lhu`; a
   width local was worse.)

### Proposed learning

- **`andi K` + `sltu $v0, $zero, $v0` for a single-bit flag: the masked
  value went through a local, `c = x & K; f = c != 0;`.** Any `(x & K)
  != 0` in one expression becomes `srl`+`andi 1` (expr.c's store-flag
  bit test). (func_80017640)
- **An `s16` field loaded `lh` before a scale whose result is stored as a
  halfword: a multiply, `w * 4`.** `w << 2` narrows to `lhu`.
  (func_80017640)
