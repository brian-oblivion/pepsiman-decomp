# func_80033A08 — MATCHED 44/44 (round 6, bravo)

Unit `src/code_1dc24.c`. Converts `deg` (degrees) to a 4096-unit angle
(`(deg << 12) / 360`, the `0xB60B60B7` magic divide), adds the yaw
`D_800A7680[0].vy`, and moves the position words at 0x348 and 0x350 of
`D_8009EB78` back by `rsin(...) * dist >> 12` and `rcos(...) * dist >> 12`.

```c
void func_80033A08(s32 deg, s32 dist) {
    s32 ang;
    SVECTOR *rot;

    rot = D_800A7680;
    ang = (deg << 12) / 360;
    sGameSave.unk348[0] -= rsin(rot->vy + ang) * dist >> 12;
    sGameSave.unk348[2] -= rcos(rot->vy + ang) * dist >> 12;
}
```

## Levers

- `deg` is `s32`: retail shifts it with no `sll 16`/`sra 16` first.
- **The angle in the register the position base reuses.** Retail keeps
  the angle in `s0` and the `D_800A7680` base in `s1`, and reuses `s0` for
  the `D_8009EB78` base once the second `addu` is done. With
  `D_800A7680[0].vy` read directly and an `ang` local (12/44, one word
  short): the base took `s0`, the angle `s1`, and the second `addu` sank
  below the `D_8009EB78` base load. Two spellings give 44/44: the base in
  a local pointer (`rot = D_800A7680;`, kept) or the angle written back
  into the parameter (`deg = (deg << 12) / 360;`).
