### The `andi` (length): a volatile empty asm

combine deletes port 1's `andi 0xFFFF` because `nonzero_bits` of the
`xor` of two shifted bytes is 0xFFFF. A bare `__asm__("")` between the xor
and the `(u16)` does NOT stop it: basic asm is `ASM_INPUT`, and
`volatile_insn_p` returns 0 for it, so `can_combine_p` combines across.
`__asm__ __volatile__("" : : )` is `ASM_OPERANDS` with the volatile bit;
`can_combine_p` rejects any volatile insn between i2 and i3, so the andi
survives and the length is exact. It has no operands and pins no register,
but it is the extended syntax: **the head must rule whether hard rule 7
allows it** (posted on the broadcast). It is also a sched barrier.
