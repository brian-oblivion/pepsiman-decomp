Unit `src/object.c`. When bits 4-5 of `gStageParams` read 1 and byte 5 of
the game state `gPlayer` is not 0x43, sets that byte to 0x42 and calls
`AddBonusLevel(-1)` (defined in `player`).


with `GameHead` holding only byte 5: retail builds the base `lui`/`addiu` into
`$a0` and reads `5($a0)`, the struct-lvalue shape (LEARNINGS, Declarations).
`gStageParams` is `lui $v0` / `lw $v0` (common.h's plain `s32`, not gp).

## The lever: non-void with no return (again)

As `void` the build was one word short: reorg filled the `beq`'s delay slot
with the `li $v0, 0x42` from the fall-through path. Retail keeps a `nop`
there. Declaring it `s32` with no `return` keeps `$v0` live at the exit and
blocks the fill, exactly as LEARNINGS records for `UpdateSpeedBand`'s forward
branch. Second build matched. Adds one "control reaches end of non-void
function" warning (to baseline).
