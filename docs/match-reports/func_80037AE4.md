## Attempts

1. Nested `if (fd != -1) { ... }` blocks with `return -1;` per failure:
   4/82, longer layout.
2. Flat `goto created/opened` with `return -1;`: equal length, 12/12
   ins/del. The -1 went to `$v0` where retail sets `$s3` in each failure's
   `j` delay slot and copies `$s3` to `$v0` once at the exit.
3. One exit, `D_800959D0 = K; ret = -1; goto end;`: 6/6. Cross-jumping
   merged the three tails `sh v0; li s3,-1; j end` into one block reached by
   `j`; retail keeps them apart.
4. `ret = -1; D_800959D0 = K; goto end;`: 82/82.

## Levers

- **A failure value set in a saved register in each `j end` delay slot and
  copied to `$v0` at one exit: a single-exit `ret` local with `goto end`.**
- **Identical fail tails (`li v0,K; sh v0,G; j end; li s3,-1`) kept apart:
  assign `ret` BEFORE the global store.** The other order lets cross-jumping
  share the `sh; ret = -1` tail.
- The `s16` counter is one variable reused by all three loops (`move s1,
  zero` before each).

### Proposed learning

- **Per-path `G = K; ret = -1; goto end;` tails that retail keeps separate:
  write `ret = -1; G = K;`.** Cross-jumping merges the matching suffix
  `sh; li ret` but not one that ends at the differing `li K; sh`.
  (func_80037AE4, func_80038F70)
