# func_80042A88 — MATCHED 62/62 (round 4, echo)

Unit `src/code_31cec.c`. Two-step sound-bank switch, driven by the state
`D_80095B0E`. Returns 1 at once when `bank` is 0 or already current
(`D_80095AFC`). In state 0 it starts loading the bank: the source entry
`&D_8007B6A4[bank]` and the size word `D_8007B6CC[bank + 6]` go to the
loader globals (`D_80096748`, `D_8009F248`), the destination
0x8016D000 to `D_8009F090`, two loader flags are set to 1 and the state
moves to 1. In state 1, once the loader's step byte `D_8009596C` reaches
6, it closes the old VAB, records `bank` and calls func_80041F28(1);
only then does it return 1.

| step | result |

| stores in the order the globals are listed in the asm (`D_8009F248` last, where retail stores it in the `j` delay slot) | 21/62, the table load scheduled after the stores |

- **A second `li $v0, 1` right before a store, with `$v0` already 1: the
  stored value is not the literal.** `D_80095B0E = 1;` reuses the 1
  already in `$v0`; `D_80095B0E++` (known 0 inside `case 0`) is folded
  to a fresh constant after CSE has passed it. A chained `a = b = 1`
  does not help.
- `ret` lives in `$a3` from the top: an `s32 ret = 0;` local returned at
  the end; the early exits return the literal 1 from branch delay slots.
- Declarations read from retail: `D_80095960` and `D_8009596C` are
  reached through `lui $at` (stores) and `lui $v1` / `lb $v1` (same
  register), so plain scalars outside the gp list; `D_8009596C` is `s8`
  (`lb`). The tables are `lui`/`addiu` + scaled index, so `[]`.
- func_80041F28 sign-extends its argument with `sll`/`sra` 16, so its
  prototype here takes `s16`.

### Proposed learning

- **A constant reloaded (`li`) right before a store although the same
  register already holds it: the source stored something CSE only folds
  late, such as `x++` on a value known from a `switch` case.**
