### Proposed learning

- **A large offset built whole (`lui/ori 0x1DFFE; addu; sh 0(reg)`) where
  the build splits it (`lui/ori 0x18000; addu; sh 0x5FFE(reg)`): the offset
  was in a local**, `off = 0x1DFFE; *(u16 *)(p + off) = v;`. A constant
  offset goes through LEGITIMIZE_ADDRESS and is split. (func_80037440)
- **A parameter sign-extended separately at each use inside a polling
  loop: the loop was a `goto` label**, not `while`/`for`; a C loop hoists
  the extension above the loop. (func_80037440)
- **`if (n++ < K)` with the increment in the branch delay slot and no copy:
  `if (n < K) { n++; goto top; }`.** The post-increment form copies the old
  value first. (func_80037440)
