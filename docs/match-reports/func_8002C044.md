Unit `src/code_1a098.c`. Walks the 16-byte directory loaded at the fixed
address 0x8017D708 (entry count in the first entry's halfword at 0xE) and,
for slots 0x33 to 0x33 + count - 1, kept in the global counter
`D_800958CC`, stores a pointer to each entry's data (directory + offset +
4) in `D_800D81B0[slot]`, copies the data's first word into the game
state's word table at 0x20, advances the pointer by one word and copies
the word after it into the table at 0x1B0.

### Proposed learning

- The order of a loop's hoisted invariants in the preheader can depend on
  the function being non-void with no `return`, like the delay-slot nops
  in the existing entry (func_8002D140, func_800283A0).
- A store `A[g] = (p = expr) + 1;` loads the index `g` before `expr`'s
  loads; with `p = expr; A[g] = p + 1;` they come the other way round.
