# func_80033854 — MATCHED 9/9 (round 1, alpha)

Unit `src/code_1a098.c`. Fills byte 0 of 200 consecutive 0x5C-byte records
with -1.

```c
void func_80033854(s8 *p)
{
    u32 i;

    for (i = 0; i < 200; i++) {
        *p = -1;
        p += 0x5C;
    }
}
```

## Levers

- **The counter is `u32`.** Retail counts up from 0 and tests with
  `sltiu`. An `s32` counter makes GCC 2.8.1 reverse the loop into a
  count-down with `bgez` (0/9, image drifts).
- **The stored byte is `s8` -1**: retail materialises `addiu $a1,$zero,-1`;
  a `u8` 0xFF gives `addiu ...,0xFF`.

The record type (0x5C bytes, a signed byte at 0) is not named yet; the
caller that owns the array will say what it is.
