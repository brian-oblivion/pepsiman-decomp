# func_80029E74 — MATCHED 301/301 (round 11, echo)

Unit `src/code_1a098.c`. The wall test behind func_8002A328's probes. It
walks zone `zone` of the floor-format data `hdr` (`FloorHdr`, the same
layout func_800299D8 reads), skips faces whose flag is set, and finds the
face whose centre (three vertices averaged with `/ 3`, four with `>> 2`)
is nearest `pos` by squared distance, ties going to the later face. With
no face it returns 0. Otherwise it takes the face normal (OuterProduct0 of
the edges v0->v2 and v0->v1, scaled down by 64, VectorNormal) and returns
-1 when `pos` is behind the face, 0 when in front.

It uses the unit's `FloorHdr`, `FloorZone`, `FloorFace`, `FloorVtx` and
func_800299D8's `VTX` macro (`#define VTX(i) ((FloorVtx *)((i) * 8 +
(s32)v))`):

```c
/** @brief Finds the face of zone `zone` of the wall data `hdr` whose centre
 *         is nearest `pos` and tells which side of it `pos` is on.
 *  @return -1 behind the nearest face, 0 in front of it or with no face */
s32 func_80029E74(s32 zone, VECTOR *pos, FloorHdr *hdr) {
    VECTOR a;
    VECTOR b;
    VECTOR n;
    FloorVtx *v;
    FloorFace *f;
    FloorFace *best;
    u32 k;
    s32 d;
    s32 min;

    min = 1000000;
    f = (FloorFace *)(((FloorZone *)(zone * 8 + (s32)hdr))[1].offset + (s32)hdr);
    v = (FloorVtx *)(hdr->vtx + (s32)hdr);
    for (k = 0; k < ((FloorZone *)(zone * 8 + (s32)hdr))[1].count; k++, f++) {
        if (f->flag != 0) {
            continue;
        }
        if (f->v[3] == 0xFFFF) {
            a.vx = (VTX(f->v[0])->x + VTX(f->v[1])->x + VTX(f->v[2])->x) / 3;
            a.vy = (VTX(f->v[0])->y + VTX(f->v[1])->y + VTX(f->v[2])->y) / 3;
            a.vz = (VTX(f->v[0])->z + VTX(f->v[1])->z + VTX(f->v[2])->z) / 3;
        } else {
            a.vx = (VTX(f->v[0])->x + VTX(f->v[1])->x + VTX(f->v[2])->x + VTX(f->v[3])->x) >> 2;
            a.vy = (VTX(f->v[0])->y + VTX(f->v[1])->y + VTX(f->v[2])->y + VTX(f->v[3])->y) >> 2;
            a.vz = (VTX(f->v[0])->z + VTX(f->v[1])->z + VTX(f->v[2])->z + VTX(f->v[3])->z) >> 2;
        }
        d = (a.vx - pos->vx) * (a.vx - pos->vx) + (a.vy - pos->vy) * (a.vy - pos->vy) +
            (a.vz - pos->vz) * (a.vz - pos->vz);
        if (d <= min) {
            min = d;
            best = f;
        }
    }
    if (min == 1000000) {
        return 0;
    }
    f = best;
    a.vx = VTX(f->v[2])->x - VTX(f->v[0])->x;
    a.vy = VTX(f->v[2])->y - VTX(f->v[0])->y;
    a.vz = VTX(f->v[2])->z - VTX(f->v[0])->z;
    b.vx = VTX(f->v[1])->x - VTX(f->v[0])->x;
    b.vy = VTX(f->v[1])->y - VTX(f->v[0])->y;
    b.vz = VTX(f->v[1])->z - VTX(f->v[0])->z;
    OuterProduct0(&a, &b, &n);
    n.vx >>= 6;
    n.vy >>= 6;
    n.vz >>= 6;
    VectorNormal(&n, &a);
    if (a.vx * (pos->vx - VTX(f->v[0])->x) + a.vy * (pos->vy - VTX(f->v[0])->y) +
            a.vz * (pos->vz - VTX(f->v[0])->z) <
        0) {
        return -1;
    }
    return 0;
}
```

## How it went

Five builds.

- First body, with a `faces` base indexed `faces[k]` for the vertices and
  the best face, and `f` stepped for the flag (from retail's two pointers
  `$s2` and `$a1` bumped by 12): 299/301, length exact, ins/del 1/1. The
  residue was the two increments at the loop bottom in swapped order
  (`a1 += 12` before `k++`).
- `f++, k++` in the `for`: worse (the `f` bump left the delay slot).
  `faces[k]` for the flag and `f` for the rest: worse.
- One pointer `f` for everything, `best = f`: 301/301. cc1 made the
  second pointer itself: `best = f` keeps a copy of `f` live across the
  bump, so loop.c split it into a giv.

`func_80029E74`'s parameter is now `FloorHdr *hdr`; the forward
prototype after it in the unit (`u8 *data`) is gone and func_8002A328's
two calls cast `D_800958B4` to `FloorHdr *` instead of `u8 *` (still
byte-exact). One `best might be used uninitialized` line added to
`config/typeviews-warnings.txt`.

### Proposed learning

- **Two pointers bumped by the same stride in one loop, one of them only
  copied out (`move t3, a1`) on a hit: a single pointer and `best = f;`.**
  Writing the second one out as `base[k]` gets everything but the order of
  the increments. (func_80029E74)
