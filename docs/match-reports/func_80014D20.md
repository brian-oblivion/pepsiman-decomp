# func_80014D20 — MATCHED (19/19), round 1, runner charlie

Clears the whole 1024x512 VRAM to black and waits for the GPU.

```c
void func_80014D20(void) {
    RECT rect;

    rect.x = 0;
    rect.y = 0;
    rect.w = 0x400;
    rect.h = 0x200;
    ClearImage(&rect, 0, 0, 0);
    DrawSync(0);
}
```

First attempt. The unit now includes Sony's `libgte.h` then `libgpu.h`
(`libgpu.h` alone fails to parse: it uses `SVECTOR`/`MATRIX` from `libgte.h`),
so `RECT`, `ClearImage` and `DrawSync` come from the SDK with Sony's own
prototypes rather than local declarations. Retail's store order (`w` first)
is the scheduler's; the C writes the fields in struct order.
