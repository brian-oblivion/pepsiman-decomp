# func_80042058 — MATCHED 62/62 (round 4, echo)

Unit `src/code_31cec.c`. Sound start-up: mixes serial input A (CD) on at
full volume, clears `D_80095AEA` and `D_80095B1A`, opens the first song
of the sequence bank loaded at 0x80101000 into slots 2..9 of
`D_800E0570` (VAB `D_80095B16`), then sets every slot's volume to 0.
Returns 0.

```c
#include "libsnd.h"
extern s16 D_800E0570[];
extern u16 D_80095B1A;
extern s16 D_80095B16;
extern s16 D_80095AEA;

s32 func_80042058(void) {
    s16 i;
    u32 *hdr;

    SsSetSerialAttr(SS_SERIAL_A, SS_MIX, SS_SON);
    SsSetSerialVol(SS_SERIAL_A, 127, 127);
    D_80095AEA = 0;
    D_80095B1A = 0;
    hdr = (u32 *)0x80101000;
    for (i = 2; i < 10; i++) {
        D_800E0570[i] = SsSeqOpen((unsigned long *)(*hdr + 0x80101000), D_80095B16);
    }
    for (i = 0; i < 10; i++) {
        SsSeqSetVol(D_800E0570[i], 0, 0);
    }
    return 0;
}
```

The bank at 0x80101000 starts with a table of 16-byte entries whose
first word is a song's offset from the bank start (func_80042150 indexes
it by song number).

## Levers

- **The constant 0x80101000 held in two saved registers (`$s2` for the
  load address, `$s1` for the addend), with the loop's `li $s0, 2`
  between them.** Written as one literal twice (`*(u32 *)K + K`), CSE
  merges the two into one register (59 words, 3 short). Two locals
  (`hdr = K; base = K;`) give two registers but both ahead of `li $s0, 2`
  (59/62 aligned). **A pointer local set before the loop plus the
  literal addend inside it** gives 62/62: the loop label stops CSE from
  replacing the in-loop literal with `hdr`, and loop.c hoists it after
  the loop's init.
- `s16 i` gives retail's `sll`/`sra` + `slti` loop tests.
- `SsSeqOpen`'s first argument is cast to `unsigned long *`: the
  project's `u_long` is `unsigned int`, and `(u_long *)` warns about an
  incompatible pointer against libsnd.h's prototype.

### Proposed learning

- **One literal address materialised twice (`lui`/`ori` into two
  registers) for a load address and an addend: the source held it in a
  pointer local for the load and wrote the literal for the addend.** CSE
  merges two literals in one block; a pointer local whose value CSE no
  longer knows (set before a loop label, or modified by `hdr += n`) keeps
  the literal separate. (func_80042058, func_80042150)
