# func_80042968 — MATCHED 19/19 (round 2, bravo)

Unit `src/code_31cec.c`. Sets the CD audio mix to `vol`: both channels
straight through (`val0`, `val2`) and, unless the flag `D_80095AEE` is
set, both cross-feeds too (`val1`, `val3`); with the flag set the
cross-feeds are 0.

```c
#include "libcd.h"

extern u8 D_80095AEE;

void func_80042968(u8 vol) {
    CdlATV atv;

    if (D_80095AEE) {
        atv.val2 = vol;
        atv.val0 = vol;
        atv.val3 = 0;
        atv.val1 = 0;
    } else {
        atv.val2 = vol;
        atv.val0 = vol;
        atv.val3 = vol;
        atv.val1 = vol;
    }
    CdMix(&atv);
}
```

`D_80095AEE` is in `config/gp-symbols.txt` (`%gp_rel` `lbu`). First try,
writing the stores in retail's order (val2, val0, val3, val1), the lever
from func_80042C14: GCC 2.8.1 keeps local struct stores in source order.
