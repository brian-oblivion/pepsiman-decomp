# func_8002CC24 — MATCHED 50/50 (round 8, alpha)

Unit `src/code_1a098.c`. Sets up all 80 `Rec78` records (`D_800D8D20`) as
objects of the TMD file at the fixed address 0x80155000, record i drawing
object i, after zeroing the count `D_8009588E`. The loop body is
func_8002C20C's body with `tmd` constant.

```c
static __inline__ void setupModel(Model70 *m, unsigned long *tmd, u8 n) {
    GsInitCoordinate2(WORLD, &m->coord);
    m->obj.coord2 = &m->coord;
    GsMapModelingData(tmd + 1);
    GsLinkObject4((unsigned long)(tmd + 3), &m->obj, n);
    m->obj.attribute = 0x200;
    m->scale.vx = 0x1000;
    m->scale.vy = 0x1000;
    m->scale.vz = 0x1000;
    m->rot.vx = 0;
    m->rot.vy = 0;
    m->rot.vz = 0;
    D_8009588E++;
}

void func_8002CC24(void) {
    u32 i;

    D_8009588E = 0;
    for (i = 0; i < 80; i++) {
        setupModel((Model70 *)&D_800D8D20[i], (unsigned long *)0x80155000, i);
    }

```

## The lever: an inlined helper with a `u8` parameter

Build 1 wrote the body out inline with `(u8)i` as the object number and
was one word short (23/50 aligned): retail copies the counter first,
`move $a2,$s2; andi $a2,$a2,0xFF`, where the cast gives a single `andi
$a2,$s2,0xFF`. The copy is the inlined parameter's own pseudo register.
A `static __inline__` helper with a `u8 n` parameter matched on build 4.

Negatives:

- Marking func_8002C20C itself `__inline__` (it is defined earlier in the
  unit) inlines it into func_8002CC24 correctly, but GCC 2.8.1 defers the
  out-of-line copy of a non-static inline function to the end of the
  unit, which breaks ROM order.
- func_8002C20C as a wrapper calling the helper does not keep its own
  match (6/41): inlined into a function where `tmd` is a parameter, the
  two-step `tmd++; tmd += 2;` advance is lost and the register pairing
  flips. So func_8002C20C keeps its own body and the helper duplicates it.

### Proposed learning

A loop body that repeats another function's code with an argument copied
to its register before an `andi 0xFF` (`move a2,s2; andi a2,a2,0xFF`): a
`static __inline__` helper with a `u8` parameter. A `(u8)` cast at the call
gives one `andi` from the counter. Do not mark the existing non-static
definition `__inline__`: 2.8.1 then emits it at the end of the unit.
(func_8002CC24)
