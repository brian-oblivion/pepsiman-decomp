## Levers

- **Both flag tests are `v & 0x80000000`.** Retail tests the first with
  `bltz` and the second with `and`/`bnez` against a `lui 0x8000` set in the
  first branch's delay slot. CSE puts the shared mask in one register;
  combine folds the first test (the mask set in the same block) into a sign
  branch and cannot fold the second (the mask comes from another block).
  `v < 0` for the first, or any spelling of the second alone, folds both.
- **Vertex stores: the zeroes last**, after the second x pair; written
  first, the scheduler hoists them into the load delay of `size->vy`.
- **The OT index read before the last UV store** (`z = v >> shift;`): the
  store through the buffer pointer may alias `v`, so retail's load of `v`
  above it is source order. The func_8002097C shape.
