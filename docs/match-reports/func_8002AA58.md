mode byte `D_800958F8` clear it tests the player's x/z (`sGameHead.unk348`
/ `unk350`, relative to the box) against the four edges of the box's

### Proposed learning

- **Offsets added together before the table symbol (`(j*6 + i*K) +
  sym`), with no reuse of a record pointer: index a real array
  declaration**, `extern T D[]; D[i].v[j]`. A cast view `((T *)D)[i]` is
  pointer arithmetic: it computes `D + i*K` first and CSE shares it with a
  record-pointer local. (func_8002AA58)
- **A register-tie residue with nothing else different can be a callee's
  declared return type**, even of a call elsewhere in the function: a
  `void` prototype for a callee whose body leaves `$v0` set moved the tie
  of a sum in another loop. (func_8002AA58, permuter find)
