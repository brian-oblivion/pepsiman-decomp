Unit `src/code_13068.c`. Converts an angle in degrees to a PlayStation
angle and writes the X and Z of a point at `radius` on that bearing:
`out->vx = rsin * radius >> 12`, `out->vz = rcos * radius >> 12`.

```c
void func_800285C8(s32 deg, s32 radius, VECTOR *out) {
    s32 angle;

    angle = ANGLE_DEG(deg);
    out->vx = rsin(angle) * radius >> FIX12_SHIFT;
    out->vz = rcos(angle) * radius >> FIX12_SHIFT;
}
```

First try. The `sll 12` then multiply by 0xB60B60B7 with `sra 8` and the
sign correction is GCC's signed division by 360 of `deg << 12`, which is
common.h's `ANGLE_DEG`. The stores at 0 and 8 of a `s32` record are
libgte's `VECTOR` `vx`/`vz`. `rsin`/`rcos` come from `libgte.h`.
