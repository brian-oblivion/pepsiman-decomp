# func_8002971C — MATCHED 34/34 (round 4, bravo)

Unit `src/code_1902c.c`. Sphere overlap test: 1 when the squared distance
between two bodies is less than the square of their radii's sum.

```c
typedef struct {
    s32 x;
    s32 y;
    s32 z;
    u8 padC[8];
    s32 radius;
} Body;

s32 func_8002971C(Body *a, Body *b) {
    VECTOR d;
    s32 dist;

    d.vx = (b->x - a->x) * (b->x - a->x);
    d.vy = (b->y - a->y) * (b->y - a->y);
    d.vz = (b->z - a->z) * (b->z - a->z);
    dist = d.vx + d.vy + d.vz;
    d.vx = (b->radius + a->radius) * (b->radius + a->radius);
    return dist < d.vx;
}
```

## Levers

- Retail stores the squared radius sum to `0($sp)`, the slot that already
  holds the squared x distance. With a separate `s32 r` local (and `return
  d.vx + d.vy + d.vz < r;`) the build drops that store and is one word
  short (oracle fails on size). Summing first and reusing `d.vx` for the
  radius term: 34/34 on the second build.

### Proposed learning

A frame-local slot stored twice with unrelated values is one local reused
by the source; a fresh temporary for the second value disappears into a
register and loses the store.
