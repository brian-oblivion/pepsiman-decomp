## Levers

Eight builds: 8 -> 27 -> 26 -> 30 -> 30 -> 25 -> 129 -> 170 -> 280 -> 308.

- **The parameter used directly through a cast, `((GameState
  *)state)->`, not a `GameState *g = (GameState *)state;` local.** With
  the local, the state block and the hoisted table base swap `$s2`/`$s3`
  (280/308, every other word right).
- **Retail reloads `unk2` at every later use: the range test reads it
  through `*(volatile u8 *)&p->unk2`.** A plain test lets cse keep the
  value in a register. With `k = p->unk2;` before the `D_8009599C`
  store the reloads come back, but the load moves above the store.
- `if ((u32)(unk2 - 15) >= 4) { ... } else { ... }` puts the kinds
  15..18 arm last, as retail. A `switch` with `case 15..18` tests two
  bounds.
- Retail loads `state->unk6` beside `unk5` before the outer switch: a
  `u8 m = unk6;` local before it.
- **Three small switches, three compare trees, each fixed by its case
  list.** The default lookup is `case 1: case 2: case 4: v = 0x42; case
  3: default: v = b[4];`; adding `case 0:` makes five nodes and a jump
  table. The 0x42 override has no `case 0`. The final dispatch has
  `case 0: default:`. An explicit or missing `case 0` decides whether the
  tree tests `== 0` first or `< 3` first.
- Each arm of the final dispatch ends with its own `unk5 = v; if
  (unk2) func_800285B0(); D_8009575F = ...; return;`. Cross-jumping then
  merges from the `if` down, as in retail. One shared tail after the
  switch also merges the `unk5` store.
- The inner jump table (`unk6` 2..51) matched with source order 0x33
  (falling into 2..4), 2..4, 8..11, 5..7.

### Proposed learning

1. A value retail reloads at every use after one test, with no store in
   between to explain it: the test read it through a volatile lvalue.
2. A pointer parameter that retail keeps in a different saved register
   than a local copy gets: use the parameter through a cast at each use.
