## Levers

- **A computed bound copied into the result (`addiu $v0, ...` in a delay
  slot, then `move $v1, $v0`): an if/else that assigns the bound in the
  else arm**, not a default assignment overwritten by the if.
- **A store at a join that reuses a saved base register: a local pointer**
  (`g = &sGame`). The struct-lvalue macro rebuilds the address there.
- **An inlined helper's parameter type moves the caller's conversion**: the
  `s16` step passed to an `s32` parameter is sign-extended before the call.
- **Loads that stay below a store to a different global:** no C spelling
  found; `__asm__("")` does it. Possibly a source-level construct that ends
  the basic block there; not identified.

### Proposed learning

A clamp whose upper bound is computed into a scratch register in a branch
delay slot and then copied into the result: `if (x <= hi) v = x; else v =
hi;`. (func_80028008)
